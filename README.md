# HXD1C 坡道驾驶与调速实操考评

独立的浏览器端铁路虚拟实训项目，第二版包含：

- 长大上坡道驾驶与调速；
- 长大下坡道调速与制动。

项目基于既有HXD1C驾驶台、线路和LKJ通用素材重新建立业务模块。运行时不读取或写入其他训练项目。

## 运行

```powershell
npm run serve
```

访问 `http://127.0.0.1:4194/`。三维线路资源通过 `fetch()` 加载，不能直接双击HTML文件运行。

## 操作

- 在实物手柄区域上下拖动牵引/电制动手柄、自阀和单阀；牵引/电制动手柄双击回零。牵引1—12级在本教学模型中分别给定10—120 km/h参考目标，6级给定60 km/h，实际平衡速度仍受坡度、载重和黏着限制；
- 自阀按运转、初制、常用制动区、全制动、抑制、重联、紧急的连续行程工作，不设置“快速缓解位”；
- 点击换向手柄区域切换位置，运行中换向由联锁拒绝；按住“单阀侧压”时单独缓解机车制动缸，松开即停止动作；
- 点击驾驶台LKJ区域放大LKJ完整原机面板；
- 点击驾驶台右侧CIR设备打开机车综合无线通信设备；坡道途中任务默认列尾已连接，只需在设备内查询风压；
- 按住右下风笛按钮鸣笛，点击中部警惕/复位热区确认LKJ报警；
- 使用顶部“呼唤确认”“撒砂”；连续重复操作不会刷分；
- 打开“运行数据”可查看首尾列车管、牵引力、电制动力和空气制动力；
- 纵断面同时显示当前阶段目标速度带、速度趋势和冲动棒；7项考评独立监测，不相互锁定；
- 手机登录后自动尝试全屏与横屏锁定，失败时使用CSS沉浸模式兜底；横屏提供固定的自阀、单阀、主手柄加减键和按住单缓键。

完整设备、热区、状态和反馈对应关系见 [CAB_CONTROL_MAPPING.md](./CAB_CONTROL_MAPPING.md)。

## 第二版轻量动力学

- HXD1C 7200 kW牵引/再生制动能力边界；
- 坡度附加力、基本运行阻力和速度积分；
- 局部湿轨黏着限制、按需撒砂和空转处置；
- 600 kPa列车管定压、首尾传播、缓解与再充风；
- 列车制动缸与机车制动缸分离、空电联锁、动力/空气制动共同作用；
- 级位突变引起的纵向冲动、车钩力代理量与可见驾驶台振动；
- 牵引热负荷、空气制动热负荷和安全红线。

当前模型用于课程原型与操作逻辑验证，不替代真实线路操纵示意图、局集团细则或机车司机手册。

## 验证

```powershell
npm test
```

自动测试覆盖项目隔离、坡度计算、12级牵引、上坡/下坡100分参考轨迹、并行评分、空电联锁、防重复操作、手机沉浸入口、纵向冲动和LKJ安全红线。学生满分路径及与实际操纵的边界见 [STUDENT_FULL_SCORE_GUIDE.md](./STUDENT_FULL_SCORE_GUIDE.md)。
