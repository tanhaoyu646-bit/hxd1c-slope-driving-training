# HXD1C 坡道驾驶与调速实操考评

独立的浏览器端铁路虚拟实训项目，第一版包含：

- 长大上坡道驾驶与调速；
- 长大下坡道调速与制动。

项目基于既有HXD1C驾驶台、线路和LKJ通用素材重新建立业务模块。运行时不读取或写入其他训练项目。

## 交路与环境

- 与“途中过分相+升降弓”采用同一条内宜线内江—内江南两站一区间；内江端约0～0.4 km，内江南站场约12.1～12.3 km。
- 坡道考评统一从区间1.25 km处开始，最长任务终点约11.45 km，完整位于两站一区间内，不另造一条孤立线路。
- 场景复用原游戏NEIYI线路数据，保留主线、邻线、道床、地形、接触网、信号、树木、房屋及两端站场环境。
- 坡度、黏着和列车动力学按课程考评工况叠加；它们是教学工况，不宣称等同于原游戏线路的实测纵断面。

## 运行

```powershell

```

访问 `http://127.0.0.1:4194/`。三维线路资源通过 `fetch()` 加载，不能直接双击HTML文件运行。

## 操作

- 在实物手柄区域上下拖动牵引/电制动手柄、自阀和单阀；牵引/电制动手柄双击回零；
- 自阀按原游戏6个功能位置与贴图帧对应；单阀按原游戏12帧连续行程显示；
- 点击换向手柄区域切换位置，运行中或牵引/电制手柄未回零时由联锁拒绝；
- 按住“单缓按钮”单独缓解机车制动缸，松开即自动复位，与原游戏 `BailOffButton` 瞬时控制一致；
- 点击驾驶台LKJ区域放大LKJ；
- 按住右下风笛按钮鸣笛，点击中部警惕/复位热区确认LKJ报警；
- 使用顶部“呼唤确认”“列尾查询”“撒砂”；
- 打开“运行数据”可查看首尾列车管、牵引力、电制动力和空气制动力；
- 纵断面同时显示当前阶段目标速度带、速度上升/下降趋势和纵向冲动等级；开始前任务书公开 7 项评分结构。

完整设备、热区、状态和反馈对应关系见 [CAB_CONTROL_MAPPING.md](./CAB_CONTROL_MAPPING.md)。

## 第一版动力学

- HXD1C 7200 kW牵引/再生制动能力边界；
- 坡度附加力、基本运行阻力和速度积分；
- 局部湿轨黏着限制、按需撒砂和空转处置；
- 500 kPa列车管定压、首尾传播、缓解与再充风；
- 列车制动缸与机车制动缸分离、空电联锁、动力/空气制动共同作用；
- 级位突变引起的纵向冲动、车钩力代理量与可见驾驶台振动；
- 牵引热负荷、空气制动热负荷和安全红线。

当前模型用于课程原型与操作逻辑验证，不替代真实线路操纵示意图、局集团细则或机车司机手册。
